# Threat Blocking and IP Filtering

## What is IP Blocking?

IP blocking prevents traffic from known malicious or untrusted IP addresses.


## When IP Blocking Is Used

- Known attacker IPs
- Repeated brute-force attempts
- Malicious scanning sources


## Limitations of IP Blocking

- Attackers can change IPs
- NAT and shared IPs can cause false positives
- Not effective against distributed attacks

IP blocking is a **defensive layer**, not a complete solution.
