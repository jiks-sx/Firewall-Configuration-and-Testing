# Firewall Logging and Monitoring

## Why Logging Matters

Firewall logs provide visibility into:
- Blocked traffic
- Allowed connections
- Scanning attempts
- Policy misconfigurations


## What Logs Can Reveal

- Suspicious IP addresses
- Repeated connection attempts
- Misconfigured rules
- Malware communication attempts


## Firewall Logs in SOC

In real environments, firewall logs feed into:
- SIEM systems
- Incident detection workflows
- Threat intelligence correlation
