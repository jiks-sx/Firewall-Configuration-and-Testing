# Types of Firewalls

## 1. Network Firewall
Placed between networks to control traffic flow.
Examples: Enterprise firewalls, perimeter firewalls.


## 2. Host-Based Firewall
Runs on individual systems.
Examples:
- UFW (Linux)
- Windows Defender Firewall


## 3. Packet-Filtering Firewall
Filters traffic based on:
- IP address
- Port
- Protocol

Fast but limited inspection.


## 4. Application-Level Firewall
Understands application protocols (HTTP, FTP).

Example: Web Application Firewall (WAF).


## 5. Next-Generation Firewall (NGFW)
Includes:
- Deep packet inspection
- Intrusion prevention
- Application awareness

Used in enterprise environments.
