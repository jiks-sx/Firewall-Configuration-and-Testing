# Firewall Fundamentals

## What is a Firewall?

A firewall is a network security control that monitors and filters
incoming and outgoing network traffic based on predefined security rules.

It acts as a **barrier between trusted and untrusted networks**.


## Why Firewalls Are Needed

Networks are constantly exposed to:
- Unauthorized access attempts
- Port scanning
- Malware communication
- Data exfiltration

Firewalls reduce attack surface by controlling:
- Which traffic is allowed
- Which traffic is blocked
- How systems communicate

## Firewall at a Conceptual Level

Firewalls operate on the principle:
"Allow only what is required, deny everything else."

This is known as **default deny** or **least privilege networking**.
