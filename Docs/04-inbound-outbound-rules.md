# Inbound and Outbound Firewall Rules 

## Inbound Rules

Control traffic **coming into** a system.

Examples:
- Allow SSH from admin IP
- Block all other incoming connections


## Outbound Rules

Control traffic **leaving** a system.

Used to:
- Prevent malware communication
- Restrict data exfiltration
- Control application behavior


## Why Both Matter

Many attacks bypass inbound rules but succeed through outbound access.

Security requires control in **both directions**.
